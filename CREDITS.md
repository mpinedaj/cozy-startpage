# Credits

## Art

All scene art and the ASCII clock are original and generated in code under `src/scene/` and
`src/ui/ascii.ts`. No third-party ASCII art, pixel art, photographs or sprite sheets are shipped with
the project, and the scenes work without any image assets at all.

`public/favicon.svg` is original to this project.

## Fonts

The interface uses a system monospace stack (Cascadia Mono, JetBrains Mono, Fira Code, ui-monospace,
SFMono-Regular, Menlo, Consolas, Liberation Mono). No webfont is bundled or downloaded.

## Services

- Weather data by [Open-Meteo](https://open-meteo.com/), used with no API key. Requests are opt-in
  and only made when the weather widget is enabled.
