# Credits

## Art

All scene art is original and drawn procedurally in code under `src/scene/`. No third-party pixel
art, photographs or sprite sheets are shipped with the project, and the scenes work without any image
assets at all.

The optional image-layer hook (`public/assets/scenes/<id>/manifest.json`) does not include any files
by default. Any layer added later must be credited here and licensed CC0 or CC-BY.

`public/favicon.svg` is original to this project.
